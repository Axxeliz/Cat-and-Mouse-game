Cat and Mouse
El juego se basa en que el raton debe de escapar de las garras del gato en un laberinto sin salida. Como lograra escapar el raton si no hay una salida? Pues es simple, esperando a que el gato se canse y deje de perseguirlo! (cuando se acaben los turnos)
